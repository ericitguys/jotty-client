Rationale: the routed hazard is the reconcile-stamped cross-drift id (text-agnostic path-match stamps the OTHER item's id after a crossing reorder while keeping row text). The cross-check catches exactly that (row.text differs from the item now at the stamped row's path). Base-engine identity (update-arm stored-path identity, reconcile matching) untouched — the review ruled the full remedy "a dedicated phase"; this closes the routed silent-mis-target class (reminder PUT, the least-destructive op) within the arm.
